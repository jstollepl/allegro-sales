# Allegro Sales

Private application for internal sales and financial analytics.

The application uses the Allegro REST API to retrieve data from the owner's Allegro seller account, including:

- orders and sold products;
- sales prices and quantities;
- billing fees and commissions;
- payment information;
- shipment and delivery information.

The retrieved data is imported into a private Google Sheets spreadsheet and used exclusively for internal business analytics and accounting purposes.

The application is intended solely for the owner's own Allegro seller account and is not offered or distributed to third parties.
